# Haptic Flex
Haptic feedback simulator of three-point flexural test, developed in Unity for the Novint Falcon device.

The user can configure the dimensions of the virtual sample and its flexural modulus ( E<sub>f</sub> ). The feedback force of the device will then be adjusted to represent the behaviour of the material at the deflection inflicted by the user interaction.
